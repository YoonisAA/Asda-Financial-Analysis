# Asda Financial Performance Analysis FY2023-FY2025

## Project Description

This project analyses the financial performance and position of Asda across FY2023-FY2025 using financial information from Bellis Finco PLC's published annual reports.

The project was created as part of my Accounting and Finance graduate portfolio to demonstrate practical skills in financial statement analysis, ratio analysis, Excel modelling, trend analysis and financial interpretation.

The analysis examines Asda's profitability, liquidity, efficiency, leverage, working capital and cash-flow performance over the three-year period.

## Project Objectives

The main objectives of this project are to:

- Analyse Asda's financial performance across three financial years
- Examine trends in revenue and profitability
- Evaluate gross and operating margins
- Assess liquidity and working-capital management
- Analyse debt and financial leverage
- Evaluate return on equity and return on capital employed
- Analyse operating, investing and financing cash flows
- Identify significant financial trends
- Present key findings through Excel charts and dashboards
- Provide concise business commentary based on the financial results

## Analysis Process

### 1. Financial Data Collection

Financial information was collected from published annual reports relating to Asda/Bellis Finco PLC.

Relevant figures from the income statement, balance sheet and cash-flow statement were organised in Excel for analysis.

### 2. Financial Statement Analysis

The workbook analyses the three core financial statements:

- Income Statement
- Balance Sheet
- Cash Flow Statement

This provides the foundation for the ratio and trend analysis.

### 3. Ratio Analysis

Financial ratios were calculated and grouped into key areas:

**Profitability**
- Gross Profit Margin
- Operating Profit Margin
- Return on Equity (ROE)
- Return on Capital Employed (ROCE)

**Liquidity and Efficiency**
- Current Ratio
- Quick Ratio
- Working Capital
- Asset Turnover
- Inventory Turnover

**Leverage and Solvency**
- Debt-to-Equity Ratio
- Liabilities-to-Assets Ratio
- Interest Coverage

### 4. Trend Analysis

The analysis compares financial performance across FY2023, FY2024 and FY2025.

Three-year trends are used to identify changes in:

- Revenue
- Profitability
- Margins
- Liquidity
- Working capital
- Financial leverage
- Cash flow

### 5. Vertical Analysis

Vertical analysis was performed to assess the relationship between major financial statement items and their relevant base figures.

This helps identify changes in Asda's cost structure, profitability and balance-sheet composition over the period.

## Profitability Analysis

Profitability analysis focuses on Asda's ability to generate profit from revenue, shareholder equity and capital employed.

Revenue growth is considered alongside gross margin and operating margin to distinguish between sales growth and improvements in underlying profitability.

ROE and ROCE are used to assess the returns generated from shareholder funds and the wider capital employed within the business.

## Liquidity and Working Capital Analysis

The current ratio and quick ratio are used to assess Asda's short-term liquidity position.

Working capital analysis provides additional insight into the relationship between current assets and current liabilities.

For a supermarket business, inventory and supplier payment cycles are particularly important when interpreting liquidity and working-capital performance.

## Leverage and Solvency Analysis

Debt and leverage ratios are used to evaluate Asda's financial structure and reliance on external financing.

The analysis considers debt relative to equity and the wider asset base, while interest coverage provides an indication of the company's ability to meet financing costs from operating profit.

## Cash-Flow Analysis

Cash-flow analysis evaluates movements across:

- Operating activities
- Investing activities
- Financing activities

This provides additional context beyond accounting profit and helps assess Asda's ability to generate cash through its underlying operations while meeting investment and financing requirements.

## Dashboard

The Excel workbook includes a financial dashboard presenting key three-year trends and performance indicators.

The dashboard is designed to provide a concise overview of Asda's financial performance and make changes across FY2023-FY2025 easier to identify.
