# Asda Financial Analysis FY2023-FY2025

## Project Overview

This project analyses the financial performance and position of Asda over the FY2023-FY2025 period using information from Bellis Finco PLC's published annual reports.

I created this project as part of my Accounting and Finance graduate portfolio to demonstrate practical skills in financial statement analysis, ratio analysis, Excel modelling and interpreting financial performance.

## Objectives

The analysis focuses on:

- Revenue and profitability trends
- Gross and operating margins
- Return on Equity (ROE)
- Return on Capital Employed (ROCE)
- Liquidity and working capital
- Cash flow performance
- Debt and leverage
- Overall financial performance across the three-year period

## Financial Analysis

The Excel workbook contains:

- Income Statement analysis
- Balance Sheet analysis
- Cash Flow analysis
- Ratio Analysis
- Three-year trend analysis
- Financial dashboard
- Written financial commentary
- Sources and methodology

## Key Findings

Revenue increased from approximately £25.6bn in FY2023 to £26.8bn in FY2024 before declining to £25.9bn in FY2025.

Statutory operating performance weakened across the period, moving from an operating profit of approximately £568.6m in FY2023 to operating losses in FY2024 and FY2025.

Operating cash flow improved from approximately £991.1m in FY2024 to £1.24bn in FY2025, despite the deterioration in statutory profitability.

Liquidity remained tight, with current and quick ratios below 1.0 and negative working capital throughout the period.

Published net debt decreased from approximately £3.83bn in FY2024 to £3.11bn in FY2025, although Asda reported higher pro-forma adjusted leverage.
